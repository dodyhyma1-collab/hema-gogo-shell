# Hema Gogo Shell

Build the core layout shell for "Hema Gogo" SaaS platform.

1. Top Navigation Bar:
- Active Project Switcher dropdown (support switching between 5 isolated tenant workspaces).
- Language Switcher: System auto-detect & manual toggle for Arabic (RTL) and English (LTR).
- Global Search Bar, Notifications Badge, and User Profile menu.
- Clean responsive layout using React and Tailwind CSS.

This project was built with [Lovable](https://lovable.dev).
